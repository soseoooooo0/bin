# 黑色星空感莲花降落视频

素材已上传，动画风格已按参考图改为黑色空间、粉色光柱与发光莲花。

- 0–2.5 秒：莲花在黑暗中旋转、发光出现。
- 2–5 秒：小孩从上方缓缓降落到莲花中央。
- 5.25–8 秒：画面快速推进，并以粉白闪光完成结尾。

## 生成 MP4
打开 **Actions** → **Render lotus baby video** → **Run workflow**。完成后在页面底部下载 `lotus-baby-video`，其中包含 `lotus-baby.mp4`。
